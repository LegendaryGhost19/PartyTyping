# PartyTyping 🎉

![PartyTyping Demo](https://via.placeholder.com/1000x500?text=Replace+this+link+with+a+screenshot+of+your+app)

**PartyTyping** is a high-performance, minimalist typing speed test application inspired by Monkeytype. Built with React and Vite, it focuses on providing a buttery-smooth, distraction-free environment to test your typing speed (WPM) and accuracy.

[Live Demo](https://your-deployment-link-here.com) <!-- Add your live link once hosted! -->

## ✨ Features

*   **Real-time Analytics:** Calculates Words Per Minute (WPM) and accuracy percentages dynamically as you type.
*   **Strict Error Tracking:** Character-by-character validation that highlights correct, incorrect, and "extra" over-typed letters.
*   **Smooth Auto-Scrolling:** The text container intelligently tracks your active word and smoothly scrolls older lines out of view, maintaining focus.
*   **Dynamic Word Generation:** Shuffles a bank of the most common English words on every restart so you never type the same test twice.
*   **Theme Engine:** Instantly toggle between Dark and Light modes using a custom CSS-variable theme engine.
*   **Persistent History:** Remembers exactly what you typed (even if you skipped words) to accurately reflect missed keystrokes.

## 🛠️ Tech Stack

*   **Frontend Framework:** React.js (Functional Components & Hooks)
*   **Build Tool:** Vite (for lightning-fast HMR and optimized builds)
*   **Styling:** Pure CSS3 (Utilizing CSS Variables for theming and Flexbox for responsive layouts)
*   **State Management:** React `useState`, `useEffect`, and `useRef` for complex DOM tracking.
